# Alif Laila Introductory Astronomy

This site hosts materials for the **Alif Laila Introductory Astronomy** program,
including observatory design documentation, instructional lessons, and practice
materials for students and outreach participants.

<div class="callout">
This project is designed for open-access education and remote astronomical
observation using a roll-off roof observatory.
</div>

## About the project

**Alif Laila Introductory Astronomy** is an educational initiative run by the
Alif Laila Book Bus Society (ALBBS). The program aims to make introductory
astronomy and hands-on telescope use accessible to students and the wider
community through a small, remotely operable roll-off roof observatory.

The observatory will support night-sky sessions, curriculum-linked lessons, and
outreach events. All design documents, lesson plans, and worksheets on this site
are shared openly so that others can adapt them for similar projects.

## What you’ll find here

- **Observatory plans** — Construction and automation details for a roll-off roof observatory, including the pier, roof mechanics, and safety systems.
- **Course materials** — Structured lessons and outreach content for introductory astronomy (hosted on Google Drive).
- **Worksheets & paper** — Practice problems and the current project paper, available as PDFs.
